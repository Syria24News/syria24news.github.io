# syria24news.github.io
Syria24News root GitHub Pages site: favicon and redirect to www.syria24.news

- `favicon.ico` و`icon-192.png` و`apple-touch-icon.png`: تولّدها مهمة «أيقونة الموقع» (`.github/workflows/favicon.yml`) من أيقونة بلوجر.
- `index.html`: تحويل إلى www.syria24.news — و`404.html` لأي رابط خاطئ.
- `feeds.opml`: كل خلاصات الموقع (الرئيسية + الأقسام) للاستيراد دفعة واحدة.
- تنبيه: لا يُضاف نطاق مخصص (CNAME) لهذا المستودع، لأنه يحوّل كل مستودعات المنظمة ومنها s24news-assets.
